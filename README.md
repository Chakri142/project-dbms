## EduCart Pro - Educational E-Commerce Web App

A professional web application inspired by Flipkart/Amazon style interfaces, built using:
- **HTML + CSS** (frontend)
- **Python** (backend server + business logic)
- **SQLite / SQL** (data storage + recommendation queries)

### Features
- Marketplace-style landing page with hero banner and category navigation
- SQL-backed course catalog with rating, learner counts, and pricing
- Category filtering from the search bar
- Recommendation panel generated from user interaction scores
- Responsive layout for desktop and mobile

### Run locally
```bash
python3 app.py
```

Then open: `http://localhost:5000`
